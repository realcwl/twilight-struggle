# 打击感 · 十套方案

关键动作成功的那一下，现在只是数字变了、底座淡入。这里是十套“打击感”，每一套都是一个完整的想法，贯穿三个时刻：

1. **控制落成**：放下最后一点影响力，达成控制，底座落到铭牌下面。
2. **政变清场**：政变把对方在该国的影响力全部清掉，对方的数字（和底座）被毁掉。
3. **骰子对决**：双方掷骰，加成点（相邻受控国、影响力占优）按节拍一个个进来，赢的骰子把输的打掉。

都跑在真实地图上，骰子就是游戏里的那颗骰子。

**已选定并合进游戏（2026-11-16）**：控制落成用 08 实木棋子；政变清掉对方时用 03 碎玻璃，随后己方达成控制仍用 08；骰子用 02 炮击，而且是通用的：任何掷骰（调整阵营、政变、太空竞赛、事件判定和对抗）都走同一套。
游戏里的实现在 `src/play/impact.ts`（三种打击）、`src/play/impactSound.ts`（合成音效）、`src/play/impact.css`，接线在 `src/play/spotlight.ts`。这个页面保留作对照。

## 我的推荐

**03 碎玻璃** 作为整套的底子：命中帧顿住约 0.1 秒再炸开，是最干净的“打到了”，三个时刻都成立，时间也最短。

但三个时刻出现的频率差得很远，正式做的时候我建议混着用，而不是一套到底：

- **控制落成**一回合会出现很多次，要短：03，或者更克制的 08。
- **政变清场**少见，可以重：03 或 05（一闪的“停一拍才裂开”很适合清场）。
- **骰子对决**是赌，要爽：02（你说的开炮）或 05；加成点的节奏最好看的是 07（电弧）和 06（筹码 + ×2 ×3）。

## 做法

- `main.ts`：十套共用的部分。地图、局面、数字怎么变、骰子、节拍和顺序。
- `variants.ts`：十套各自的四个打击点 `control` `wipe` `bonus` `win`，加一个小号的 `tap`。
- `kit.ts`：特效工具箱。震屏、顿帧、闪光、扩散环、粒子、闪电、裂纹、弹道、切成两半。
- `sfx.ts`：声音，全部用 WebAudio 现场合成，没有音频文件。
- 链接参数：`?v=01..10`、`&play=control|wipe|duel|all`、`&speed=0.35`、`&mute`、`&ui=0`。页面就绪后 `<html>` 带 `ready` 类；`window.proto` 有 `pick(id)`、`play(moment)`、`kit`。
