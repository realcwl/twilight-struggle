# 大区识别：十种方案

要解决的问题：地图上看不出一个国家属于哪个大区。现在唯一的线索是最远视角下的六个大区名，以及悬停时信息卡里的一行字。

> **2026-11-14 更新：选定 04 大区字签，已接进游戏。** 实现在 `src/map`（`regionStyle.ts` 配色与字、`plates.ts` 和 `map.css` 的铭牌字签格、`legend.ts` 图例、信息卡里的徽标）。接入时把字签的宽度从其他几格里匀了出来，所以最远视角下铭牌和原来一样大，不再有下面“已知的小毛病”里说的变宽问题。
>
> 这个页面现在会把游戏自带的字签藏起来、把各格宽度还原，所以 00 仍然是合并前的样子，十个方案照旧可以对比。下面的内容是选型时写的，保留作记录。

这个文件夹是十种做法的原型，全部跑在游戏真实的地图上，可以随时切换、叠加。原型本身只从外面往地图上加东西；游戏不依赖这个文件夹。

## 怎么看

**先看图册**（不用开服务）：直接用浏览器打开 `gallery.html`。每个方案两张截图，最远视角和近看各一张。

**再上真实地图**（可以缩放、悬停、叠加）：

```
npm run dev
```

然后打开 <http://localhost:5173/prototypes/region-identity/>。

| 操作 | 作用 |
|---|---|
| 底部 00–10 | 切换方案。00 是现状，用来对照 |
| `←` `→` | 上一个 / 下一个 |
| `1`–`9`、`0` | 直达 01–09、10；`` ` `` 回到现状 |
| 勾“叠加”，或按住 Shift 点 | 把几个方案叠在一起看 |
| 顶部的视角按钮 | 跳到全球、欧洲、三区交界、非洲、亚洲、美洲 |
| “局势”按钮 | 演示局势和空盘之间切换，看大区色和蓝、红控制色会不会打架 |
| 左下角图例 | 指上去点亮整个大区，点一下飞过去 |
| `H` | 藏起切换条，只留地图和图例 |

网址会记住选了哪些方案（`?v=03,09`），刷新不丢。还可以手动加上视角，例如 `?v=03,09&view=junction` 一打开就是“03 加 09，看三区交界”。

## 十个方案

| # | 名称 | 画在哪 | 最远视角 | 近看 | 主要代价 |
|---|---|---|---|---|---|
| 01 | 铭牌底色 | 节点 | 强 | 强 | 铭牌不再是统一深色，蓝、红影响力格要和底色抢对比度 |
| 02 | 彩色底座 | 节点 | 中 | 中 | 色块只是一条边；铭牌高了几个像素 |
| 03 | 稳定度徽章 | 节点 | 中 | 强 | 战场国的金色圆章没了，只剩金圈和章内金环 |
| 04 | 大区字签 | 节点 | 弱 | 强，还带一个字 | 铭牌变宽，最远视角更挤 |
| 05 | 名签旗框 | 节点 | 弱到中 | 强 | 名签比描边文字占地方；旗框小 |
| 06 | 领土染色 | 地面 | 强 | 强 | 和控制方的蓝、红染色抢同一块面积 |
| 07 | 大区描边 | 地面 | 中 | 弱到中 | 内陆小国身上没有颜色 |
| 08 | 大区纹理 | 地面 | 弱 | 强，但很吵 | 拉远后线纹糊成淡色；和“有影响力无人控制”的斜纹相似 |
| 09 | 连线着色 | 连线 | 强 | 中 | 线细，孤立看一个节点时要顺着线找 |
| 10 | 大区底板 | 地面 | 中到强 | 中 | 色板跟连线走，会盖到海上和别国领土上 |

“强、中、弱”是我对着截图做的判断，不是测量结果。

## 我的建议：03 + 09

页面上有个“推荐组合”按钮，一键切到这个组合。

理由按重要程度排：

1. **大区是计分单位，属于主信息，应该放在主信息层上。** 节点和连线是玩家真正在读的东西，地图只是氛围。所以首选画在节点或连线上的方案，地面方案（06、07、08、10）只适合做补充。
2. **两个都不增加任何东西。** 03 借用已有的稳定度圆章，09 借用已有的连线。铭牌不变宽不变高，最远视角的密度不受影响。
3. **两个互补。** 03 回答“这一个国家属于哪”，近看最清楚；09 回答“这一片是哪个大区”，最远视角下同色的网一眼成团。单独用 03，远看偏弱；单独用 09，孤立节点不好认。
4. **不碰蓝、红、金。** 控制方用边框和影响力格的蓝、红，战场国用金色外圈，这些都原样保留。

两个需要你拍板的地方：

- **如果你要的就是桌游那种“底色即大区”的直观感，选 01。** 它在所有方案里最醒目。代价是铭牌从统一的深色变成六种颜色，亚洲的粉色铭牌配红色影响力格、欧洲的紫色铭牌配蓝色影响力格，会比现在浑一些。把“局势”切到演示再看 01，这个问题最明显。
- **如果还想在地面上加一层，我选 06 而不是 07。** 07 更克制，但实际效果偏弱，尤其是近看。06 清楚得多，只是要接受它和控制方染色叠在一起时颜色会混。

## 配色

六个大区色避开了已经有含义的三种颜色：蓝（美国）、红（苏联）、金（战场国）。

| 大区 | 颜色 | 说明 |
|---|---|---|
| 欧洲 | `#ab8fff` 紫 | 海岸线最长的两个大区用离海水颜色最远的两个色 |
| 亚洲 | `#f27ab1` 粉 | 同上 |
| 中东 | `#2fc6b4` 青绿 | 落在沙漠底色上，对比够 |
| 非洲 | `#b4d23c` 黄绿 | |
| 中美洲 | `#dc9058` 铜 | |
| 南美洲 | `#4fc272` 绿 | |

第一版把青绿给了欧洲，结果 07 的描边和浅海的青绿色融在一起，几乎看不见，所以换了。这也说明地面方案天然受地貌和海水底色的干扰，节点方案没有这个问题。

没有解决的：

- **色弱。** 黄绿、绿、青绿三个色对红绿色弱的人不够分明。只有 04（带字）和 08（带纹理）在颜色之外多了一重编码。定稿前配色需要专门过一遍。
- **粉和红、紫和蓝是邻近色。** 目前靠明度拉开，在小尺寸的铭牌上够用，但不算宽裕。

## 接进游戏要改什么

原型里每个方案都是从外面加上去的。真正接入时的改动大致如下，供估工作量：

| 方案 | 改动 |
|---|---|
| 01–05 | `plates.ts` 给每个铭牌写上大区和大区色；`map.css` 加对应样式。02、04 各多一个元素 |
| 06–08 | 并进 `terrain.ts` 的地形 shader，大区色写进 `territoryState.ts` 那张数据贴图。并进去以后能和控制方染色一起调，比现在叠一层的效果好 |
| 09 | `links.ts` 的区内连线从一批改成按大区分批，或给 `lineBatch.ts` 加逐段颜色 |
| 10 | 新增一个地面图层，启动时烘焙一张距离场贴图（现在约 2048×1152） |
| 图例 | 新的界面元素，哪个方案都需要 |

大区色本身建议放进剧本数据（`regions[].color`），不要写死在代码里。

## 已知的小毛病

- 10 的色板在三条连线围成的小空隙里会留一个三角形的洞。
- 03 的战场国金环在最远视角下很细。
- 04 让铭牌在最远视角宽了约 5 像素，相邻铭牌的外圈会轻微相碰。
- 切换条和顶部按钮会挡住一部分地图，按 `H` 藏起来。
- 页面伸手改了地图模块的若干私有成员（见 `main.ts` 里的 `Internals`）。地图模块的内部结构一变，这个原型就可能要跟着改。
