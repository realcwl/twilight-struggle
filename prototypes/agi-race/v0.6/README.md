# AGI 争霸 2022–2030（暂名）· 规则草稿

一页讲规则的站点，用来和设计者一起改规则，不是视觉稿。数值都还没调。

## 现在的版本：v0.6（2026-11-16），只动文字的一版

设计者这次定的：

- 地图要像冷战热斗那样一个地区一个地区地聚在一起，不要逻辑上的大区。做五个方案来选。
- 算力、数据、人才不再是三条要堆满的进度条，而是三条 −3 到 +3 的科技线：领先的一方每一格都有加成；投入要花掉一个行动轮。
- 分数回来了，最终分数多的赢。
- 记分牌回来了，早期和中期各洗进一批。
- 这一版不做游戏，只写规则。

页面上的做法：

- R3 五个地图方案（按大洲的天然大小、整齐六区、紧凑五区、大区套子区、七区），各有一张按方位摆的示意图，后面是对比表。设计者说国家少了，所以都加过一轮：30 到 42 个市场。我倾向方案二（6 × 6 = 36）。
- R4 分数条、记分怎么算（存在 2 / 支配 4 / 控制 6，关键市场各 +1）、记分牌的规矩、终局。
- R5 三条科技线：九个加成沿用上一版进度条上的那九个；投入是掷骰，点数不超过牌值 + 2 就成，每年一次，事件不发生。
- R6b 运气调低（设计者说太吃运气、垄断太容易丢）：垄断拿下之后有 1 点余量；收购对手垄断着的市场门槛 +2；骰子不再爆。数字是在单机版引擎上量的（`tools/mono.ts`）。
- R7 资本压力的差额换成对手的分数；资本开支把投入也算上。
- R10 加了记分牌；5 张牌因为规则变了改写；牌面上的地名等地图定了再改（牌表里带「地名待改」）。

我补的都列在 R2b 和 Q1–Q12 里。从单机版模拟里带过来的四条（开局不垄断、收购封顶、轮流发牌、融资难度年终回落 2 级）在 R2c。

已经做出来的单机版（`~/dev/agi/prototypes/demo`）用的还是 v0.5.2 的规则。

## 怎么看

直接打开 `index.html`（不需要服务器，不依赖游戏代码）。

## 怎么提意见

每条规则、每张牌都有编号（R6、E07、Q1…）。报编号说怎么改；
或者在页面上点「批注」写下来，右上角「复制全部批注」会把它们拼成一段文字。
批注只存在这台电脑的浏览器里。
