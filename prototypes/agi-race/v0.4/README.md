# AGI 争霸 2022–2030（暂名）· 规则草稿

一页讲规则的站点，用来和设计者一起改规则，不是视觉稿。
主体是三样：游戏节奏（三个时代）、全部 93 张事件牌的文字、让牌与牌自己长出组合的那套东西（突破、常驻、通用事件）。数值都还没调。

## 怎么看

直接打开 `index.html`（不需要服务器，不依赖游戏代码）。

## 文件

| 文件 | 内容 |
|---|---|
| `data.js` | 全部内容：93 张事件牌、6 张记分牌、26 张突破、10 张大势、17 种通用事件、6 个组合示例、回合表、地图、三条基建线。**改规则和改牌改这里** |
| `index.html` | 核心玩法与和冷战热斗的对比（R0）、规则正文（R1–R13）、还开着的 8 个问题（Q3–Q10） |
| `app.js` | 把数据画出来；垄断演示、收购和检定的概率计算器、连锁浏览器、批注 |
| `style.css` | 线框版面 |

`data.js` 里每张牌和每张突破都标了 `out`（它让哪些通用事件发生）和 `on` / `opp`（它在等自己或对面的哪些事件）。
连锁那一节完全靠这些标注，改牌面时要一起改。

## 怎么提意见

每条规则、每张牌都有编号（R6a、E07、算3、D02、C1…）。报编号说怎么改；
或者在页面上点「批注」写下来，右上角「复制全部批注」会把它们拼成一段文字。
批注只存在这台电脑的浏览器里。牌的编号在各版之间保持不变。

## 版本

**v0.4（2026-11-16）** 设计者定下的五件事，替换掉之前的两项提议（份额条、年度报告）。

- 垄断按差额算：每个市场有重量级，份额比对手多出的数达到重量级就是垄断；份额没有上限
- 大区记分三档：存在、支配、控制
- 用记分牌：6 张，跟着大区的时代进牌堆，抽到的那一年必须打出
- 牌库两头的差距收到 1 张（早期美 11 / 中 10，后期美 8 / 中 9；新增 E32、L25）
- 资本压力 3 / 4 / 5
- 23 张牌面从「格」改成「点份额」；E09、M06、L05、数7 单独重写

**v0.3（2026-11-16）** 基建改成三条线：算力（芯片、数据中心、电）、数据（训练数据）、人才（核心科学家）。

- 26 张突破重新分进三个池子，编号改成 算1–9、数1–9、人1–8
- 三条线各有一种加注：算力线交 GPU，数据线靠垄断的市场，人才线弃手牌
- AGI 工程不再挂在某条线顶上：骰子 + 牌值 + 三条线等级之和，对门槛 18，三种加注都能押
- 开局：美国人才线 1 级、3 个 GPU；中国数据线 1 级、1 个 GPU
- 自备电改由算力线的突破和几张牌给；电力那条表的规则没变
- 新增 3 张讲数据的牌（E31、M35、M36），14 张牌面改了线名

**v0.2（2026-11-16）** 按三条意见改：要有 roguelike 那种想不到的组合；运气占三到五成；牌太机械。

- 88 张牌全部重写：每张牌从那件事本身出发，有自己的小动作（扣下再赎、暗标、同时表态、预告跳票、欠账……）
- 基建改成掷骰；升级时翻 3 张突破留 1 张
- 新资源 GPU：1 个 GPU 重掷一次
- 全游戏一套骰子：6 爆，1 砸
- 牌与牌不再互相点名，只通过通用事件发生关系
- 每个时代翻一张大势
- 拓展和电力故意不掷骰

**v0.1（2026-11-16）** 第一版骨架：9 回合三个时代；份额条与垄断；收购；资本压力；电力余量；基建四线；年度报告代替记分牌；早期美国略优、后期中国略优。

2022–2026 的牌取自真事，日期凭记忆写的，定稿前要核对；2027 年以后的都是推演。
