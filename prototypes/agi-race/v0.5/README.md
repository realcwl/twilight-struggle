# AGI 争霸 2022–2030（暂名）· 规则草稿

一页讲规则的站点，用来和设计者一起改规则，不是视觉稿。数值都还没调。

## 现在的版本：v0.5.2（2026-11-16），推倒重来之后的一版

设计者定的新地基：

- 胜利只有一种：把算力、数据、人才三条进度条都堆满（做出 AGI）。没有分数，没有记分牌。
- 进度条只能靠地图推：每年年终，按你在各个大区垄断的市场推进。没有基建行动。
- 一张牌只有两种用法：当事件，或当行动点（拓展 / 收购）。对手的事件照样触发。
- 每条进度条一样长；推到某些格子给增益，要少、要一看就懂。增益只给先到的一方，对手也到了就作废。
- 地图不按时代上锁：24 个市场从第一年全开，靠早、中、后期的牌把战场带到不同的大区。
- 没有电力。换成融资难度（双方共用，1 到 5）：收购关键市场让它上升，越高，被禁止收购的大区越多。
- 资本压力：每年收购的总额要达到当时的融资难度；差得少的一方拿到差额那么多点，用来让对方的进度条退格。

我补的，都等确认：每条 12 格；3 / 6 / 9 格各一个增益；6 个大区 24 个市场，每个大区只喂一条进度条，六个大区每年都推条；
年终怎么推有四种算法（基线「三档」加三种替代，我倾向「数产地」）；融资难度每一级禁哪些大区（芯片链 → 欧洲 → 中东 → 东南亚和英联邦，全球南方一直能买）；
GPU、突破、大势、掷出 1 就砸都拿掉了；93 张牌按新规则过了一遍，编号和牌名不变。

## 怎么看

直接打开 `index.html`（不需要服务器，不依赖游戏代码）。年终记分的四种算法在 R6，有一块可以点的棋盘。

## 怎么提意见

每条规则、每张牌都有编号（R6、E07、Q1…）。报编号说怎么改；
或者在页面上点「批注」写下来，右上角「复制全部批注」会把它们拼成一段文字。
批注只存在这台电脑的浏览器里。
