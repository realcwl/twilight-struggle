# 二级界面 · 十套方案

> **已选定并合入游戏（2026-11-16）：09 象牙白，去掉标题角上的印章。**
> 游戏里的共用样式是 `src/ui/sheet.css`，用法写在它的开头。这里的十套只留作对照，以后改样式改那一份。

游戏里的二级界面（选牌、选先后顺序、卡牌详情、术语提示、牌堆浏览、确认框、通知条）现在各做各的，风格不统一。
这里是十套统一的风格，每一套都把同样的七个界面画了一遍，目标是高端桌游实物的质感。
游戏本身（`src/`）没有动；卡牌用的是游戏自己的渲染和数据。

## 怎么看

开发服务器开着时（`npm run dev`）：<http://localhost:5173/prototypes/secondary-ui/>

- 顶上一排是十套方案，点一下切换；`← →` 或数字键 `1`–`9`、`0` 也可以。
- 第二排“十种并排看”：选一个界面，十套方案排在一起比。`G` 开关。
- 界面里可以点：选牌、选项、筛选签都会换选中状态，按钮有悬停和按下的样子。

链接参数：`?v=01..10`、`&compare=pick|order|detail|tip|pile|confirm`。

## 七个界面

| 界面 | 对应游戏里的 |
|---|---|
| 选一张牌 | 拿取对手的牌、从弃牌堆收回、亮出手牌后选择 |
| 先后顺序 | 打出对手的事件牌：先事件还是先行动点 |
| 卡牌详情 | 悬停在牌上：历史背景和规则要点 |
| 术语提示 | 悬停在牌面的规则术语上 |
| 牌堆浏览 | 弃牌堆、移出游戏、对手可能有的牌 |
| 确认与通知 | 要点一下的确认框，和不打断的通知条 |
| 基础组件 | 按钮、筛选签、阵营签、按键提示 |

## 我的看法

01 最稳：和现在的 HUD 同色同料，统一起来改动最小。
想更像“桌上的实物”，把 03 的绿呢牌槽借给 01（凡是放卡牌的地方都铺呢面）。
04 和卡牌最亲，但浅色大面积压在深色地图上偏重。
05 和 09 是离现在最远的两个方向，一个更现代，一个更安静。

## 合进游戏以后

选的是 09。合并时没有照搬这里的 `sx-` 样式，而是写成一份共用的“纸页”样式 `src/ui/sheet.css`（类名 `sheet`、`sheet-head`、`sheet-btn`、`sheet-row`、`sheet-pick`…），各个界面自己的样式文件只留布局。

已换成纸页的：
选牌 / 选项 / 亮牌 / 提示 / 结算 / 菜单（`src/game/solo/presenter.ts` + `solo.css`，联机房间菜单在 `src/net/client.ts`）、
术语 / 历史故事 / 关联卡牌 / 国家说明（`src/cards/tooltips.js` + `terms.css`）、
牌堆和“对手可能有的牌”（`src/hud/pileBrowser.ts`，样式在 `hud.css`）、
牌库（`src/cards/library.*`、`filters.*`）、
对局记录（`src/hud/parts/battleLog.ts` + `battleLog.css`）、
持续效果详情（`src/hud/parts/passives.ts` + `passives.css`）、
声音设置（`src/audio/controls.ts` + `sound.css`）。

没有换的，仍是 HUD 的深色：国家 / 地区简报、局势详情和太空竞赛里程碑提示（它们是 HUD 表盘的读数）、
打牌时的用途选择和计分演示（聚光灯演出的一部分）、新手教程面板、联机大厅和聊天。

字体用的是游戏其它地方已经在用的两组（标题同 HUD 的宋体一组，正文是系统黑体一组），不需要新的字体文件。
