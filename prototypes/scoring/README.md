# 记分 · 十种呈现

现在的记分是一块四页的面板（控制的国家 → 判定档位 → 计算加分 → 双方抵消），每页停四五秒，有上一步、暂停、完成三个按钮。
问题有三个：像幻灯片；慢（一个区域将近二十秒）；一页一页翻完，仍然不容易一眼看出“谁得了多少、为什么”。

这里是十种替代的呈现，都跑在真实的地图和真实的 HUD 上，数字来自引擎自己的记分结果（`Match.scoring()`）。

## 已选定：09 结算小票（2026-11-16）

**已合进游戏（同一天）。** 游戏里的版本在 `src/play/scoring.ts` 和 `src/play/scoring.css`，日志里的明细表在 `src/hud/parts/scoringLog.ts`。这个文件夹留作十个方案的对照，之后改游戏里的记分请改 `src/`，不要改这里。和原型不同的地方：

- 记分之后引擎那一步“胜利点变化”不再单独演（原来右上角面板会飞到屏幕中间放大）：分数已经在小票里数进去了，那一步只负责让它生效。
- 解释卡站在小票旁边，是在 `src/cards/tooltips.js` 里做的，不再事后挪。
- 声音用游戏自己的（`src/play/impactSound.ts` 和 `vp` 音效），不再借「打击感」原型的。
- 系统设置了“减少动态效果”时：没有飞行、震屏、闪光，字和等待不变。
- 窄屏（手机）上小票停靠在屏幕底部。
- 欧洲“控制即获胜”有自己的收场：不算分，砸下「直接获胜」，等你点继续。
- 自动化测试的速度（`?pace=0.05`）下没有人在场，小票打完自己继续。

十个里选的是 09。选定时提了三点，已经做进去（`slip.ts`）。页面现在默认打开的就是它。

**1. 慢下来。** 原来整张小票一秒打完。现在一行出来、看清、再出下一行；每个加分的国家，那一分是从地图上那个国家飞到它那一行上的。欧洲这局从开始到结果砸下来约 6 秒，加上记进胜利点共约 7.7 秒（原来 3 秒）。各种行停多久是 `slip.ts` 顶上的 `PACE`，一处可调。着急的时候点一下地图或按空格，直接到结果。

**2. 停住，自己点继续。** 净得分砸下来、记进胜利点以后，小票完整地留在原处，底下一个「继续」按钮（空格和回车也行）。不点就一直在，没有倒计时。

**3. 一层一层往里看。** 小票本身仍然只有几样：谁、什么档位、哪些国家加分、小计、净得分。其余的收在后面：

| 想知道 | 怎么看 |
|---|---|
| 这个词什么意思（计分、存在、支配、控制、战场国、胜利点） | 鼠标移到带虚线的词上，出来的是游戏里卡牌用的同一张解释卡（带演示画面） |
| 这个国家现在什么情况 | 鼠标移到国名上：出这个国家的卡片，地图把它点亮；它不在画面里的话，地图会转过去 |
| 为什么是这个档位 | 每一方有一行「控制 N 国 · 战场国 M/K」，这两个数就是档位的来历；鼠标移上去，地图上这一方的国家亮一遍 |
| 具体是哪些国家、差在哪 | 点那一行右边的「明细」：展开一句话的原因，和这一方全部国家的名单（不加分的也在里面，都能悬停） |

解释卡出现在小票的左边，不压住小票。

## 十种共有的东西

- **没有页，没有按钮。** 一个区域从开始到结束 2.2–4.3 秒（多数在 3.5–4 秒），另加镜头移动 0.7 秒；其中最后一秒多是结算那一下。点一下地图或按空格，剩下的部分立刻跑完。
- **镜头**对准这次计分真正相关的国家：该区域的战场国和加分的国家一定在画面里，其余被控制的国家由近到远收进来，只要不把镜头拉远太多。所以澳大利亚不会让整个亚洲变小，没人控制的远处成员（欧洲计分时的加拿大）也不会把镜头拉远。区域以外的国家变暗。
- **国家自己会动。** 轮到哪个国家，它的铭牌就跳一下、放出一圈本方颜色的光；加分的国家冒出 `+1`，飞到这一方的总分上。
- **结尾相同，而且是整段的重头。** 见下面「结算这一下」。
- **计分牌留在左边**结算的位置上，所以每个方案都是和它一起看的。
- **日志里有明细**（`L` 键）：十种共用一个设计，内容和动画完全一致，但排成可以慢慢读的表。见下面「日志」。

## 结算这一下

前面数分是铺垫，这一下才是要给人感觉的地方。十种共用同一个收尾，分四拍：

1. **砸下来。** 净得分变成一枚大牌子（`苏联 +6`），从两倍多大砸到原位。砸中的一瞬间画面定格几十毫秒，然后震屏、闪一下光、屏幕四边染上得分方的颜色，牌子背后转出一圈光芒；挣到这些分的国家在地图上一起亮一次。
2. **停一口气。** 牌子在原地鼓一下，大约四分之一秒。这是让人看清“谁、得了多少”的时间。
3. **飞过去。** 带着一道拖尾飞进右上角的胜利点。
4. **一分一分记进去。** 右上角的面板被撞得一抖、亮起得分方的光；数字一格一格跳，每一格响一声，最后一格跳得最大，再炸一圈火花。

几条规则：

- **分多分少，力度不同。** 得 1 分只是轻轻一下，得 6 分以上才是满的震屏、闪光和轰的一声。不然每次都一样响，很快就麻木了。
- **自己得分和对手得分，感觉不同。** 自己得分：金色火花，一格一格是上行的金币声，分多时收一小段号角。对手得分：每一格是鼓点，收尾是一记闷响，分多时加一声铜管和低鸣，屏幕四边是对手的颜色。前者是爽，后者是压迫。
- **反超会喊出来。** 数字跳过零、领先方换人的那一格，闪一下金光，胜利点下面弹出「反超」（被对手超过时是「被反超」）。
- **相抵为零**不砸牌子：一声闷响，一小团灰，写「双方抵消」。

每个方案在定出胜负的那一下还各有一点自己的东西：

| 编号 | 自己的那一下 |

## 日志

三个要求里的第三个：不熟悉规则的人可以去日志里读懂。按 `L` 打开的那张表就是日志详情里这一条的样子：

- 最上面是结果：`苏联 +6 VP`，以及胜利点从哪到哪。
- 一行“列表里的样子”：日志左侧列表里显示的那一句。
- 一张两列的表：控制的国家（列出名字，战场国带步枪标记，邻接的标“邻”）、其中战场国、档位（附一句为什么是这个档位）、战场国加分、邻接加分、合计。
- 底下一句相抵的算式，和这个区域的档位表、档位的定义。有穿梭外交之类的修正时也写在这里。

它画在游戏已有的象牙色纸面上（`src/ui/sheet.css`），可以原样放进 `src/hud/parts/battleLog.ts` 的详情栏。

## 我原来的推荐（选定之前写的）

**01 拔河条。** 理由：

- 它只有一样东西要看，而且这样东西本身就是答案：哪边长、长多少。
- “相抵”不用解释：两边一样长的那段一起变灰、缩掉，剩下的就是净得分。
- 它和右上角胜利点本来的画法（一条拉锯的轨道）是同一种语言。
- 3.6 秒，全程没有一个字需要读；想读的人有档位两个字和两个数字。

想要更有冲击力选 **05 对撞**；想要每个数的来历最清楚选 **03 比分牌**。
10 战场席位对老手信息量最高，但非战场国只剩一个数字，新手会觉得跳了一步。

## 还没做的

- 欧洲“控制即获胜”没有单独的呈现。选定方案后，在它的结尾上加一个胜利的收场。
- 合进游戏时，记分之后引擎还会单独结算一次“胜利点变化”（右上角面板飞到屏幕中间放大）。记分动画已经把这一步演完了，那一次需要改成不再演。
- 声音借用了「打击感」原型的合成音，只是占位；金币声、鼓点、号角这些该换成游戏自己的音色。
- 结算时的震屏和闪光没有做“减少动态效果”的版本；合进游戏时要跟系统设置走。
- 非洲、南美这类南北很长的区域，镜头要拉得比较远，铭牌会比较小；用顶部面板的方案（04、06、07、10）更明显，因为面板占了高度。
- 只在 1600×900 的窗口上核对过，没有看手机尺寸。
- 09 的解释卡“站在小票旁边”，在原型里是事后把它挪过去的；合进游戏时是 `src/cards/tooltips.js` 里一行的事。
- 09 的「继续」没有超时。联机对局里一方一直不点会怎样，合进游戏时要定。
- 两张总览图是选定之前截的，里面的 09 还是旧样子。

## 链接参数

`?v=01..10`（不写就是已选的 09）、`&s=europe|asia|mideast|camerica|africa|sea`、`&ui=0`（不显示工具条）、`&speed=0.35`、`&mute=1`、`&play=1`（打开就播）、`&log=1`（打开就显示日志明细）、`&auto=1`（脚本驱动时自己按「继续」）。
页面就绪后 `<html>` 带 `ready` 类；每次播完 `<html data-done="方案:局面:序号">`。
`window.proto` 有 `play()`、`pick(id)`、`choose(id)`、`view`（这次计分的数字）、`variants`、`situations`、`map`、`hud`、`match`。
