# 战场国标志：十个方案

> **结果：选定 02 交叉步枪，已经接进游戏（2026-11-14）。** 游戏里的画稿在 `src/map/battleMark.ts`，位置在 `src/map/map.css` 的 `.wm-battle`；金圈和金色圆章已经从游戏里去掉。这个文件夹留作其余九个方案的记录，游戏不依赖它。因为游戏已经变了，这个页面自己把旧的金圈画了回来（00“旧样式”），并且藏起了游戏自带的标志，这样十个方案仍然是和旧样式比。

要解决的问题：原来战场国和非战场国只靠颜色区分（金色外圈加金色的稳定度圆章）。这里试的是另一种做法：战场国的铭牌上戴一枚小小的、画出来的“交战”标志，金圈和金章去掉。

这个文件夹是十个标志的原型，全部跑在游戏真实的地图上，可以随时切换。原型只从外面往铭牌上加东西，`src/` 里没有任何文件知道它。

## 怎么看

```
npm run dev
```

然后打开 <http://localhost:5173/prototypes/battleground-marks/>。

## 十个方案

| # | 名称 | 戴在哪 | 是什么 | 主要代价 |
|---|---|---|---|---|
| 01 | 军刀章 | 左上角 | 黑漆圆章，金边，两把交叉的军刀 | 最常见的画法，没有惊喜 |
| 02 | 交叉步枪 | 左上角 | 两支交叉的步枪，没有底章，只有深色描边 | 拉远后只是一个“X”，细节要近看 |
| 03 | 烽火 | 左上角 | 一盆烽火，火苗轻轻跳动 | 会动的东西有 29 个；红橙色靠近苏联的红 |
| 04 | 爆芒 | 稳定度背后 | 铭牌左端背后炸开的星芒 | 最醒目也最闹；尖角伸到旗帜和邻国边上 |
| 05 | 准星 | 稳定度背后 | 套在铭牌左端的金色准星 | 线细，拉远后偏弱 |
| 06 | 钢盔 | 左上角 | 一顶银灰色钢盔扣在角上 | 含义比刀剑绕；不如金、红醒目 |
| 07 | 火药桶 | 左上角 | 拖着引信的圆炸弹，火星闪烁 | 偏俏皮；黑色弹体在深色海面上弱 |
| 08 | 对峙 | 底边 | 蓝、红两个箭头顶在一起的小牌 | 用了已有含义的蓝和红；会碰到南边邻国的国名 |
| 09 | 坦克 | 左上角 | 一辆金色小坦克 | 和“军事行动”栏的坦克太像，可能被误读 |
| 10 | 朱印 | 左上角 | 朱红印章，白文“战”字 | 拉远后是红色方块，最容易和苏联的影响力格混 |

十个标志都是手画的矢量图（`marks.ts`），没有用任何外部素材。

## 三种位置

- **左上角**（七个）：标志别在铭牌的左上角。近看时斜挂在角外，不挡上方的国名；铭牌收窄后爬到上沿、旗帜旁边，这样既不遮稳定度数字，也不伸进左边的邻国。国名始终画在标志上面。
- **稳定度背后**（04、05）：标志垫在铭牌左端下面，只从四周露出来，不占铭牌上任何位置。
- **底边**（08）：挂在铭牌底边中间。

## 我当时的建议：01 军刀章

（最后选的是 02。下面是选之前写的理由，原样保留。）

理由按重要程度排：

1. **一眼能读懂。** 交叉刀剑是地图上表示“交战”的通用记号，不需要解释。钢盔、烽火、火药桶都好看，但要多想一步。
2. **不借用任何已有含义的颜色。** 黑漆加金边，和界面四角的材质一致；蓝、红仍然只表示美苏。
3. **远近都成立。** 圆形在最远视角下仍是一个完整的小圆章，不像步枪、坦克那样糊成一团线。

如果你想要更有“画”的感觉，我的第二选择是 **03 烽火**：暖色的火在冷色地图上很好看，轻微的跳动也和地图上已有的环境动效是一路的。代价是它偏红。

**04 爆芒**是十个里拉到最远时唯一比现在的金圈更醒目的，但一屏 29 个确实闹。

## 需要你知道的

- **拉到最远时，左上角的标志只有十三四个像素**，比现在的金圈弱。这是“小标志”这个方向本身的代价，不是哪一个方案的问题。页面上可以用“大小”和“金圈”两个按钮试两种补救：把标志放大，或者在最远视角下把金圈留着。
- **相邻铭牌会互相压到。** 欧洲、中东最挤的地方，一个国家的标志会盖住左边邻国铭牌右端的一小块（例如波兰的标志压在东德的大区字签上）。接进游戏时可以让标志在最挤的缩放级别再收小一点，原型里没有做。
- **强、弱、闹这些判断是我对着截图得出的，不是测量结果。**
- **只在 Chrome 里看过。** 没有测 Safari 和 Firefox。

## 接进游戏时做了什么

- `src/map/battleMark.ts`：02 的画稿。和原型的区别只有一处：枪托的渐变改成了三块平涂，这样画稿不带任何 id，可以在页面上重复任意多次。
- `src/map/plates.ts` 给每个战场国的铭牌多加一个元素，`src/map/map.css` 的 `.wm-battle` 负责定位（位置和大小与原型的“中”档相同），并去掉了 `.wm-plate.key` 的金圈和金章。
- 原来用“★”表示战场国的地方都换成了同一幅画：地图自带的国家卡片、游戏页的国家卡片、地区卡片上的战场国计数、沙盒面板的国家列表。
- 上面“需要你知道的”前两条（最远视角下偏弱、挤的地方压到邻国）在游戏里仍然成立。
