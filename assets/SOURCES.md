# Asset sources

Everything the map draws comes from the public datasets below, or is generated by code in this
repository. Nothing is taken from any commercial game.

`manifest.json` is the download list; `npm run assets:fetch` downloads it into `assets/raw/` (not
committed) and records each file's SHA-256 in `manifest.lock.json`, which later runs verify.

## Downloaded data

| Use | Source | Version | License | File |
|---|---|---|---|---|
| Country polygons, coastlines | Natural Earth, Admin 0 – Map Units, 1:50m | 5.1.2 | Public domain | `ne_50m_admin_0_map_units.geojson` |
| Lakes | Natural Earth, Lakes, 1:50m | 5.1.2 | Public domain | `ne_50m_lakes.geojson` |
| Sub-national outlines, only for cutting custom historical shapes | Natural Earth, Admin 1 – States, Provinces, 1:10m | 5.1.2 | Public domain | `ne_10m_admin_1_states_provinces.geojson` |
| Land cover colour reference | Natural Earth II (land cover only, no relief), 1:10m low-res raster | 2.0.0 | Public domain | `NE2_LR_LC.zip` |
| Land elevation and sea-floor depth | NOAA NCEI ETOPO 2022, 60 arc-second, ice surface | v1 | Public domain (U.S. Government work) | `ETOPO_2022_v1_60s_N90W180_surface.tif` |
| Chinese label and UI typeface | Noto Serif SC (Source Han Serif), variable | google/fonts `main` | SIL Open Font License 1.1 | `NotoSerifSC-wght.ttf` |
| Latin display typeface | Cinzel, variable | google/fonts `main` | SIL Open Font License 1.1 | `Cinzel-wght.ttf` |

Natural Earth: <https://www.naturalearthdata.com/> (vector data via
<https://github.com/nvkelso/natural-earth-vector>, tag `v5.1.2`).
ETOPO 2022: NOAA National Centers for Environmental Information, doi:10.25921/fd45-gt74.
The two font license texts are downloaded next to the fonts (`*-OFL.txt`).

The two fonts are pinned by checksum rather than by tag, because google/fonts does not tag releases.
If upstream changes, `assets:fetch` stops with a mismatch instead of silently using a different file.

## What is derived from them

`npm run mapgen -- <scenario>` writes `public/maps/<scenario>/`:

| File | Made from |
|---|---|
| `ids.png` | Natural Earth polygons, grouped into the scenario's countries |
| `edge.webp`, `coast.webp`, `sea.webp` | Distance fields computed from `ids.png` |
| `height.webp`, `depth.webp`, `shade.webp` | ETOPO 2022: reshaped relief, sea-floor depth, light baked from one key light |
| `albedo.webp` | Natural Earth II land cover, re-coloured by example (`tools/mapgen/albedo.ts`) |
| `display.woff2`, `text.woff2` | The two fonts, cut down to the glyphs the scenario and the UI use |
| `map.json` | The scenario, derived land links, anchors and bounds |

## Generated in code, no source file

- Brush-stroke and paper-grain detail textures (`src/map/textures.ts`), made at start-up.
- East Germany's outline in `data/scenarios/coldwar/shapes.geojson`, assembled from Natural Earth
  admin-1 states by `tools/mapgen/make-coldwar-shapes.ts`.

## Not used

The plan lists ambientCG and Poly Haven as fallbacks for detail textures. Nothing from them is in
use: the procedural textures were enough.
