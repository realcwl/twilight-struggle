# 卡牌历史故事

110 张正式牌（含中国牌、全部计分牌与 103–110 可选牌）均有独立中文条目。每条约 200–250 字，以一个引子和三段叙事交代起因、转折、后果；正文是原创历史概述，不取用桌游的背景说明文字。计分牌讲地区背景，概念牌讲历史现象，两张电影相关牌明确区分虚构作品与真实事件。

## 入口与交互

- 悬停卡牌标题，显示系统问号光标，并在原有术语说明容器中打开历史故事。标题没有新增边框或装饰。
- 手中的牌在指针移进故事时保持展开；被动牌详情亦然。点击标题不会开始拖牌或出牌。
- 标题可通过 Tab 聚焦，Enter/空格进入浮层；Esc 或关闭按钮返回。手机点按标题阅读。
- 同一套 renderer 覆盖手牌、牌库、各牌堆、被动效果与公开出牌。说明里的缩略卡预览保留 `interactive:false`，不产生递归浮层。
- 浮层中可滚动、展开史料链接；长内容与图片尺寸变化后重新定位。历史与规则帮助共享一个容器，切换时清理旧内容，历史模式不加载术语视频。

## 内容与来源

`src/cards/history.json` 是故事的唯一数据源，按数字牌号索引。字段：`title`、`period`、`kind`、`lead`、`paragraphs`、`sources`，以及可选 `image`。

内容核对于 2026-11-15。每条都附延伸阅读链接。主要参考相应的百科条目；关键机构、军售、营救与电影条目另参照美国国务院外交史料、NORAD、美加政府档案、FBI、美国国会图书馆等。资料中的争议保留为争议；日期、人物与事件不可由牌的游戏效果反向推断。

特别注意：法国离开的是北约一体化军事指挥体系；1963 年禁试条约不禁地下试验；1973 年石油禁运不能直接等同全部 OPEC；运河完全移交在 1999 年；加拿大营救不能照抄电影追逐情节；登月照片中的人为奥尔德林，摄影者是阿姆斯特朗。

10 张真实历史图像（9 张照片及一张当年邮票）存于 `public/cards/history/`，全部本地压缩 WebP，首次打开相应故事才请求。原始比例不变，无生成式修改。照片图注显示作者、档案来源、许可链接；完整清单见该目录的 `CREDITS.md`。本轮没有生成图冒充档案照片。

## 实现与验证

- `src/cards/render.js` 为完整正面标题增加 `data-card-history` 入口。
- `src/cards/history.js` 首次请求才动态载入故事数据，转义文字后输出图文。游戏引擎不导入该数据。
- `src/cards/tooltips.js` 复用委托事件、top-layer popover、延迟关闭、手牌/被动牌保持展开事件及焦点恢复；异步结果只更新仍然激活的标题。
- `src/cards/terms.css` 增加阅读排版；`src/cards/library.ts` 将标题和历史内容视为独立交互，避免触发牌库导航。
- `npm run cards:check` 包括 110 牌覆盖、有效来源、图片与许可、不可交互预览、HTML 转义等检查。
- `HISTORY_CDP_PORT=<私人测试浏览器端口> node tools/card-history-browser.mjs` 检查全 110 个标题、悬停/焦点/键盘、手牌保持展开、术语切换、牌库、废牌堆、被动牌、手机点按与滚动。测试只使用指定的临时浏览器。

### 本轮验证结果

- 110 个真实标题入口逐一打开正确故事；手牌、牌库、弃牌堆、被动效果均通过实际指针交互。
- Enter、空格、Esc、关闭后重新悬停，以及 390×844 手机尺寸下的点按、内部滚动通过。
- 16 项卡牌检查、TypeScript 检查、新的历史浏览器检查与原有卡牌交互检查通过。旧检查中“情况面板必须在骰子左侧”的位置假设改为矩形不相交，同时保留国家目标与公式结果的遮挡检查。
- 线上验证：故事块在首次打开标题前不请求，载入后含 110 条；10 张图像、来源署名、单机与在线入口均正常响应，无页面异常。
- 发布版本：`320c8c48-eaaf-4ea0-a758-af35009b7014`。线上截图：`docs/validation/card-history.webp`。
- 本轮浏览器验证使用 Chrome（手机交互为触屏与视口模拟），未单独验证 Safari/Firefox。
