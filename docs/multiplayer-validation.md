## 发布可重放性

账户原本没有 workers.dev 子域名。首次创建通过 `infra/cloudflare.json` + `tools/cloudflare-bootstrap.mjs`，不是控制台手工配置。相同 `npm run deploy` 再次执行只更新资源与代码，核对子域名，保留 Durable Object 房间数据。

尚未验证 Safari、Firefox、手机触摸拖牌、跨洲弱网和高并发负载。这次验收是两名朋友的桌面浏览器对局。刷新会放弃尚未提交的本地放置预览，已提交的决定会恢复。原浏览器凭证保存在 localStorage；目前没有跨设备找回座位。
