# English / Spanish / Chinese validation

Local validation on 2026-11-17. No deployment was performed.

## Automated checks

| Check | Result |
| --- | --- |
| Main regression suite | 221 passed |
| Online regression suite | 46 passed |
| Card / glossary / media checks | 16 passed |
| Audio checks | 3 passed |
| Localization checks | 7 passed |
| Application and Worker type checks | Passed |
| Production build | Passed |

Localization checks cover matching message keys and interpolation parameters, 110 cards in
each language, unchanged rule quantities in Spanish, 32 glossary entries, all 22 help-video
caption timelines, 110 history summaries and credits, safe markup, semantic reference IDs,
and saved-message translation.

Fifteen complete deterministic games (five seeds in each language) reached results. Their
complete saved rule states, excluding presentation logs, were identical across languages.
This includes RNG, flags, actions, hands, decks, influence, tracks and winners.

## Browser and multiplayer play

Disposable Chrome profiles were used; existing browser sessions and saves were not touched.

- All three languages: lobby, initial deployment through real country clicks, headline,
  card drag, event choice and a decisive event reaching a victory screen.
- All 330 card layouts fit their rules/title areas. Terms remain highlighted and interactive.
  Spanish glossary help fits a 390 × 844 viewport.
- Switching languages retains the saved hand and board. A switch requested during placement
  waits until deployment is saved; choosing the current language cancels that request.
- English and Spanish tutorials each completed 70 steps using 24 real gestures. Both reached
  turn two with the same VP, crisis and space state. Reload/resume, free-play continuation,
  restart, exit, blocked illegal gestures and reduced-motion video controls passed.
  Seventeen videos used during each tutorial decoded with localized captions.
- Two browser seats used English and Spanish in the same local room. Setup, sealed headlines,
  reconnect, reload, switching language while waiting, inspection during the opponent's turn
  and preservation of authoritative room state passed.
- Two local network matches reached winners: turn-ten final scoring and a turn-four VP win.
  Room authentication/capacity, hidden headlines, reconnect, duplicate requests, public-state
  agreement and private reveal history passed.

No browser exceptions were reported by these flows. Safari and Firefox were not tested.

## Presentation boundaries

Historical notes in English and Spanish use concise summaries with original sources/photos.
Video explanations reuse the existing map recordings, with translated title and caption
overlays; small labels baked into the recording remain in their original language.

The build reports a large-library chunk warning (approximately 1.25 MB, 354 KB
gzipped). The build succeeds. Runtime localization uses bundled catalogs, with no external
translation service and no language field added to the shared match state.
